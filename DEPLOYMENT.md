# Deployment Guide

## Streamlit Community Cloud
1. Create a Streamlit Community Cloud app from this public repository.
2. Select `app.py` as the main file.
3. Deploy.
4. Use the generated public URL as the working prototype link.

## Demo flow
1. Open CycloneShield AI.
2. Select **Severe Bay of Bengal cyclone**.
3. Select **Digha** or **Paradip**.
4. Demonstrate the score and risk level.
5. Increase wind speed and storm surge.
6. Show vulnerability drivers.
7. Show the interactive map.
8. Show infrastructure exposure and recommended actions.
